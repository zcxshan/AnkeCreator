# 全局 UI 美化、性能优化与转盘重新设计 — 设计规格

> 日期：2026-09-30
> 状态：待用户审阅
> 前置：已完成上一阶段「编辑器重构 + bug 修复 + UI 升级」（2026-09-29 spec + plan，Task 1–10），本规格在其基础上继续。

## 1. 目标与范围

用户目标（原文）：
1. 美化各个界面的 UI 设计，重新构造各界面布局。
2. 优化项目各功能性能。
3. 重新设计并优化转盘功能。
4. 去掉文本图标，换成更美观的图标。

已确认的关键决策：
- **美化范围**：全部页面统一升级（非仅重点页）。
- **转盘视觉方向**：扁平极简（去彩色扇区，弱化动画，强调信息密度）。
- **性能重点**：编辑器流畅度 + 首页/列表加载（N+1 压测驱动）。
- **图标范围**：全项目 emoji → lucide-react 线性图标统一替换。

四个子工程共享同一套设计系统基础，故合并为单一 spec，实施时按工作流拆分计划。

## 2. 执行方案

选择 **方案 A：统一设计系统先行，分阶段落地**。
- 先建全局设计系统（骨架/组件/间距/图标规范），再逐页重构。
- 性能优化穿插各页重构；编辑器性能专项单独做。
- 每页独立验证、回归风险低、全项目风格一致。

## 3. 子工程 1：全局设计系统与页面骨架

### 3.1 视觉语言唯一来源：index.css CSS 变量
- 以现有 `--bg-*`、`--text-*`、`--accent`、`--success/--warning/--error`、`--radius-*`、`--shadow-*`、`--space-*` 为统一 token。
- 清理散落内联 style 中硬编码的颜色/圆角/间距，改为引用 token。

### 3.2 统一页面骨架（三要素）
- 页头：返回按钮 + 标题 + 右侧操作区，`sticky top-0` + 底边框。
- 内容区：`max-w` 居中容器 + 统一上下 padding（semantic spacing：4/8/12/16/24px）。
- 底栏：操作按钮右对齐 / 分页。

### 3.3 卡片/按钮/输入标准
- 以 CSS 工具类（`.anke-card`、`.anke-btn`、`.anke-input`…）为主，减少新增 JS 组件。
- 统一：圆角 `--radius-lg`、边框 `1px var(--border-color)`、hover 阴影 `--shadow-sm → --shadow-md` 过渡。
- 弹窗沿用 `.anke-overlay` + 卡片内层，统一锁滚动。

### 3.4 间距落实到页
- 逐页将 Tailwind 硬编码间距替换为语义层级 `--space-*`（或保留 Tailwind 但确保层级一致）。

## 4. 子工程 2：全项目图标替换（emoji → Lucide）

- 使用已安装的 `lucide-react`（^1.48.0）。
- 分类替换表（初稿）：
  - 转盘页：🎡→`FerrisWheel`(或 `LifeBuoy` 兜底)、🎯→`Target`、📝→`FileText`、🤖→`Bot`、🕒→`Clock`、🎲→`Dices`、✏️→`PenLine`、📤/📥→`Download`/`Upload`、📋→`Copy`、🗑→`Trash2`、📜→`ScrollText`、🎉→`PartyPopper`、🔄→`RotateCcw`、←→`ArrowLeft`。
  - 首页：📝→`FileText`、🎲→`Dices`、📚→`BookOpen`、🕒→`Clock`、📖→`BookOpenText`、✏️→`PenLine`、🗂️→`FolderOpen`、↗/→→`ArrowRight`、✒️→`PenLine`、💾→`Save`、🎡→`FerrisWheel`、🔍→`Search`。
  - 收集/教程/资源库：📜→`ScrollText`、📚→`BookOpenText`。
  - 工具栏（已完成）：不再重复。
- 迁移规则：图标组件统一 `size`（按钮内 16、卡片图标 20、状态大图标 48）、`aria-hidden`、统一 `stroke-width`。
- **回归注意**：BBCode 转换与阅读注入依赖 DOM 结构（如 `collapse-toggle svg`），图标替换保持 SVG 结构稳定，不改变既有语义类名与 dataset。

## 5. 子工程 3：性能优化

### 5.1 编辑器流畅度（专项）
- 检查 `contenteditable` 输入/光标/样式应用路径，避免每次击键触发全量状态重算或全 DOM 重建。
- 对 `onInput`/`onSelectionChange` 高频回调做节流/去抖与最小化 setState。
- 大文档（长节）输入/滚动卡顿优化：样式应用走局部 DOM 操作，命中缓存。
- 验证方式：手动输入长文 + 快速样式切换，观察无明显卡顿；现有 774 测试不回归。

### 5.2 首页/列表加载
- 首页统计已用 `db.listStoriesWithStats()` 聚合（修过 N+1）——复核是否仍有按故事逐个 `filter` 骰子记录的重复扫描，改为一次 Map 索引。
- 资源库/作品列表图片惰性加载（`loading="lazy"` + 图片缓存），减少首屏 IO。
- 列表渲染大项用 React.memo + 稳定 key，避免无谓重渲染。

### 5.3 转盘动画性能（列入转盘改造一部分）
- 旋转只用 `transform`（已具备），确保无布局抖动；扁平极简风格下减少不必要动画层。

## 6. 子工程 4：转盘功能重新设计（扁平极简）

### 6.1 视觉
- 扇区：去掉高饱和彩色循环，改为极简底色板（中性灰阶 + 单一强调色标识中奖扇区），强弱交替可选。
- 指针、中心圆统一为扁平几何（无渐变/无厚重阴影）。
- 信息密度优先：结果卡片、阶段进度、变量 chips 采用紧凑排版 + 统一 token。

### 6.2 组件调整
- `WheelCanvas.tsx`：重写配色为扁平调，保留 transform 旋转 + 高亮；文本沿径向渲染逻辑不变。
- `WheelPlayground.tsx`：抽取阶段结果卡片化；「抽取完成」界面精简为清晰的结果清单 + Prompt + 操作按钮。
- `SchemeEditor.tsx`：阶段/选项行使用统一卡片/输入 token，进阶折叠保持。
- `WheelPage.tsx`：列表卡片按新骨架重排，历史记录卡片化。

### 6.3 交互与逻辑
- 保留阶段链式抽取、权重抽取、去重（unique）、drawCount、变量/条件/公式、Prompt 模板渲染、历史落库。
- 不改动抽取算法与数据结构，仅视觉与排版重构（低回归风险）。

## 7. 实施顺序（供 writing-plans 拆分）

1. 全局设计系统 + CSS token 落地 + 图标替换基础（骨架、通用工具类、Lucide 迁移规则）。
2. 逐页重构：首页 → 作品列表 → 编辑/阅读页 → 资源库 → 教程/收集 → 骰子。
3. 性能专项：编辑器流畅度；首页/列表加载复核。
4. 转盘三视图重构（扁平极简）。
5. 全量回归（测试 + tsc + 浏览器验证）。

## 8. 非目标（YAGNI）
- 不加新功能（不新增收集/分享/云同步等未要求能力）。
- 不改预设模板内容（遵循用户画像约束）。
- 不改转盘数据模型与抽取算法（仅视觉重构）。

## 9. 验收标准
- 全页面共用统一设计 token，无可访问的内联硬编码配色/圆角。
- 全项目 emoji/文本图标替换为 lucide，SVG 结构稳定，BBCode/阅读注入不回归。
- 转盘呈扁平极简风，抽取流程/结果/历史正常。
- `npx tsc --noEmit` 零错误；`npm test` 全量通过（含既有 774 基线，环境性 2 项除外）。
- 浏览器实测各页面布局、图标渲染、转盘交互无误。
