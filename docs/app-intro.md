# 安科作者助手 · 应用介绍文案

> 一句话简介：用骰子编织故事 —— 一款专为安科 / 安价创作设计的写作工具，把骰子、设定、人物和正文收进同一本贴纸手账。

---

## 长文案（可直接发帖 / 发公众号）

**写安科最痛苦的，从来不是没灵感。**

是写着写着，骰子结果散落在聊天记录里；
是人物差分存在三个文件夹；
是世界观设定写在第 47 楼的回复里；
是终于写完了，还要手动把正文改成 BBCode，一行行补 `[b]`、`[quote]`、`[img]`。

**安科作者助手**就是为这件事做的。它不是又一个通用笔记软件，而是从安科创作者的动线出发：投骰 → 记设定 → 排章节 → 导出帖子，全程在一个窗口里完成。

> **【截图 ①｜请手动放入】**
> 画面建议：首页「我的安科作品」列表，展示 3～5 个作品卡片、右上角「新建安科」按钮。
> 建议尺寸：1440×900（亮色主题）。

### 🎲 骰子不是外挂，是正文的一部分

数值骰支持 `NdM±K` 和表达式（比如 `2*3d100`），选项骰支持批量粘贴 NGA 楼层文本，自动整理成选项。投掷结果直接以卡片形式落进正文，导出时自动变成 NGA 认得的 `[b]…ROLL…[/b]` 或 `[quote]` 骰楼。

> **【截图 ②｜请手动放入】**
> 画面建议：编辑器中插入的骰子卡片 + 右侧「玩骰子」面板同时入镜。
> 建议尺寸：1440×900。

### 📖 卷 / 章 / 节，加上一条随时能改的大纲

目录支持多卷、多章、多节，拖拽排序，也能**跨卷、跨章拖动**。旁边的大纲面板与目录双向同步——先列骨架，再填血肉，写到一半改结构也不用重排。

> **【截图 ③｜请手动放入】**
> 画面建议：编辑页左侧章节树 + 右侧大纲面板（或大纲页）同屏。
> 建议尺寸：1440×900。

### 👤 人物差分、世界观、关系图，各归各位

人物有属性、差分图批量上传、按人物 / 按差分两种视图；世界观是结构化设定，可套模板；人物关系可以画成关系图。这些数据跟着作品走，换电脑用 `.anke.json` 一键备份还原。

> **【截图 ④｜请手动放入】**
> 画面建议：右栏「人物」面板（差分缩略图网格）+ 人物关系图页面各一张，可拼成 2 张图。
> 建议尺寸：1440×900。

### 🖼️ 图片粘贴即用，不用再和防盗链搏斗

编辑器自动处理 NGA 图床域名失效（`img.nga.178.com` ↔ `img.nga.cn` 自动重试），导出时把附件地址还原成 `[img]./mon_20xxxx/...[/img]` 这种 NGA 站内相对路径，粘到论坛里能正常显示。图片存储可选远端图床或本地保存，本地模式会在编辑区顶部常驻提醒。

> **【截图 ⑤｜请手动放入】**
> 画面建议：一段图文混排正文，其中包含 1～2 张图片块；如需展示本地模式警告条，可另截一张。
> 建议尺寸：1440×900。

### 📥 收集安价，不用一页页翻楼层

填主题帖地址和匹配文本（留空 = 抓全部楼层），自动检测总楼层、限流抖动 + 失败重试、抓取中可取消，结果可直接导入「我的作品」。也能收集 NGA / 骨碌碌的安科作品，并在「寻找安科」页按标题 / 作者搜索。

> **【截图 ⑥｜请手动放入】**
> 画面建议：「收集安价」页面的抓取进度条 + 抓取结果列表。
> 建议尺寸：1440×900。

### 📋 写完就能发：BBCode、EPUB、阅读模式

编辑器有「可视化 / BBCode」双视图，正文共用同一份内容。颜色、字号、字体、加粗、列表、引用、折叠、代码、表格、链接、骰子全部映射到 NGA 标签；还能导出 EPUB 电子书，图片离线打包进书里。

> **【截图 ⑦｜请手动放入】**
> 画面建议：BBCode 视图全屏一张；阅读模式一张；EPUB 导出成功提示一张（三选二即可）。
> 建议尺寸：1440×900。

### 📱 Windows 与 Android，同一套 UI

桌面端是 Electron，手机端是 Capacitor。界面统一走二次元贴纸手账风：墨线描边、粉色强调、圆角贴纸卡片，亮 / 暗双主题都做了适配。手机端底部导航、键盘弹起避让、样式面板默认折叠这些细节都单独调过。

> **【截图 ⑧｜请手动放入】**
> 画面建议：Android 真机或模拟器截图，展示首页 + 编辑页（竖屏），可两张并排。
> 建议尺寸：1080×2400（竖屏）。

### 最后

安科的核心是「不可预测」，但创作过程不该跟着一起失控。
**安科作者助手**把可控的部分收拾干净，把不可控的部分留给骰子。

- 平台：Windows（安装包） / Android（APK）
- 数据：本地 JSON，自动快照，随时导出 `.anke.json`
- 授权：MIT
